## Part 1: Soil Science & Farm Management

An introduction for livestock owners, pasture managers, and beginning agronomy students. Covers soil formation, sand/silt/clay, soil structure and pore space, root respiration, pH, soil organisms, and plant roots.

The PDF includes a field exercise comparing pasture, woodland, and open-field soils, an observation record, and a knowledge check with answers. Carry out the field exercise only when soil is safely workable, rather than frozen or saturated.

The class is named **Agronomy Fundamentals**. This first supplied PDF retains its original printed heading, **Agronomy 101 — Lesson 1: Soil Science & Farm Management**; the original document has not been modified.

## Adding the next part

Add the next PDF to `downloads/` using a numbered name such as `part-02-<topic>.pdf`, add it to the table above and this class’s `downloads` list in the root `index.json`, then run `python3 scripts/validate.py` from the repository root. Keep all parts of this class together in this folder. Editable document source files can be placed in a `source/` subfolder when supplied.
