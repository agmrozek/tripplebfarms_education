## Lesson 1: Soil Science & Farm Management

How soil forms and varies across a farm. Covers the soil-forming factors, soil horizons, texture and structure, water and pore space, roots, soil organisms, and pH. Includes a 15–20 minute observation comparing two contrasting locations, an observation table, and a frozen-ground alternative.

The original first PDF has been replaced with the supplied expanded four-page edition. The stable Lesson 1 file path is unchanged; earlier versions remain in Git history.

## Lesson 2: Soil Chemistry & Cation Exchange

Nutrient retention and soil acidity: cation exchange capacity (CEC), base saturation, active and reserve acidity, lime, and the behavior of nitrogen, phosphorus, and potassium. Includes a hypothetical two-zone pasture soil test, worked lime and fertilizer quantities, and a practical sampling-plan activity.

The worked example uses fictional values for teaching; it is not a soil test or application recommendation for Tripple B Farms.

## Adding the next lesson

Add the next PDF to downloads/ using a numbered name such as part-03-<topic>.pdf, add it to the table above and this class’s downloads list in the root index.json, then run python3 scripts/update_contents.py from the repository root to validate and refresh the table of contents. Keep all lessons of this class together in this folder. Editable document source files can be placed in a source/ subfolder when supplied.
